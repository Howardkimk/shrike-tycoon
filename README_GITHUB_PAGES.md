# Shrike Tycoon 0.5.1 — GitHub Pages root deploy

이 폴더의 **내용물 전체**를 GitHub 저장소 루트에 업로드하세요.

필수 루트 파일:
- `index.html`
- `app.js`
- `styles.css`
- `manifest.webmanifest`
- `sw.js`
- `.nojekyll`  ← 숨김 파일
- `assets/`

## `.nojekyll`이 안 보일 때
`.nojekyll`은 점(.)으로 시작하는 숨김 파일입니다.
- macOS Finder: `Command + Shift + .` 로 숨김 파일 표시
- Windows Explorer: 보기 → 표시 → 숨긴 항목
- GitHub 웹 업로드에서는 파일을 직접 드래그하면 업로드 가능합니다.

GitHub Pages 설정:
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save
