# 때까치 타이쿤 — PWA 보완 패치

대상: howardkimk/shrike-tycoon, 0.8.4.12
기준 커밋: 3358728e24d7824ed245eabd99cd34facd303ec5

## GitHub Desktop으로 적용

1. GitHub Desktop에서 shrike-tycoon 저장소를 선택합니다.
2. Repository → Show in Finder로 저장소 폴더를 엽니다.
3. 압축파일 내용을 저장소의 index.html이 있는 폴더에 복사합니다.
   index.html, manifest.webmanifest, sw.js, app.js, dist/game.js는 교체합니다.
   pwa.js, .nojekyll, 이 안내 파일은 추가합니다.
   기존 assets 폴더는 그대로 필요합니다. 이 압축파일은 전체 게임이 아닌 변경 파일입니다.
4. GitHub Desktop에서 변경 파일을 확인하고 Summary에 `Improve PWA installation and offline support`를 입력합니다.
5. Commit to main → Push origin을 누릅니다.
6. GitHub Actions의 Pages 배포 완료 후 https://howardkimk.github.io/shrike-tycoon/ 를 엽니다.

## 처음 패치를 적용할 때

기존 캐시가 있으면 이전 화면이 한 번 표시될 수 있습니다. 인터넷에 연결해 게임을 열고 다운로드를 기다린 뒤, 해당 게임의 모든 브라우저 탭과 홈 화면 앱을 닫고 다시 실행하세요. 사이트 데이터 삭제는 저장된 진행도를 지우므로 업데이트 방법으로 사용하지 마세요.

## 홈 화면 설치

- 아이폰: Safari → 공유 → 홈 화면에 추가. '웹 앱으로 열기'가 표시되면 켭니다.
- 안드로이드: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가. 게임 안의 앱 설치 버튼도 사용할 수 있습니다.
- 홈 화면 아이콘으로 실행하면 주소창 없는 독립 화면으로 열립니다.
- 메뉴는 세로, 게임은 가로로 안내하는 기존 동작을 유지합니다. 기기 회전 잠금은 사용자가 해제해야 합니다.

## 오프라인과 업데이트

- 처음 실행할 때 약 115MB의 게임·그림·폰트·BGM을 저장합니다.
- '게임 방법' 하단의 '오프라인 저장 완료'를 확인한 후 오프라인으로 사용하세요.
- 홈 화면 앱에서도 인터넷에 연결한 상태로 한 번 실행하고 저장 완료를 확인하세요.
- 저장 공간 부족이나 다운로드 실패 시 도움말에 실패 안내가 표시됩니다. 연결·공간을 확인하고 다시 여세요.
- 새 버전은 미리 저장하고, 열려 있는 게임 탭과 앱을 모두 닫은 후 다시 열 때 적용합니다. 플레이 중 강제 새로고침하지 않습니다.
- 기기가 캐시를 정리하면 오프라인 파일을 다시 받아야 합니다. 진행도는 기존 localStorage 키를 유지하며, 기기·브라우저·설치 방식 사이에서 자동 동기화되지 않습니다.
- 향후 게임 파일을 수정해 배포할 때 sw.js의 CACHE 버전도 반드시 변경하세요. 새 리소스는 ASSETS 목록에 추가하세요.

## 변경 범위

게임 규칙·밸런스·새 이미지·BGM·기존 저장 키는 수정하지 않았습니다.
설치 안내를 pwa.js로 분리하고 iOS 안내를 추가했습니다.
전체 캐시 저장 후 활성화, 캐시 버전 분리, 오디오 Range 응답, 리소스 오류 시 HTML 오반환 방지를 적용했습니다.
기존 아이콘을 그대로 사용하며 검증되지 않은 maskable 선언을 제거했습니다.

## 검증

로컬 Chromium에서 최초 설치, 전체 리소스 저장, 서버 종료 후 오프라인 재실행, 이미지·스크립트 로딩, 오디오 부분 요청, 저장 키 유지 여부를 확인합니다.
iPhone 사용자 에이전트에서 설치 안내를 점검합니다. 실제 iOS Safari·Android 기기 테스트와 GitHub Pages 배포는 별도로 확인해야 합니다.
