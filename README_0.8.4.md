# Shrike Tycoon 0.8.4

Visual Style Guide v1.0 적용 업데이트. 0.8.3을 기반으로 합니다.

- 플레이 화면에서 Chef를 조리대의 중심 캐릭터로 확대하고 손님 새의 크기를 조정했습니다.
- 모바일 가로 화면의 ‘오늘의 손님’에 20px 높이의 전용 제목 행을 확보했습니다.
- 결과 화면에 선택한 Chef와 해당 Stage 서식지의 손님 새를 추가했습니다.
- Bird Book과 ShrikeDex 상세 초상화의 전시 공간을 넓혔습니다.
- reduced motion 설정과 기존 조작, 0.6.5.11 게임플레이·콘텐츠를 유지했습니다.

`shrike-tycoon-prototype-0.8.4.zip`에는 TypeScript 소스가 있습니다. `shrike-tycoon-web-0.8.4.zip`과 `shrike-tycoon-github-pages-0.8.4.zip`은 정적 배포 파일입니다.
